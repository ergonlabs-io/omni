`omni` launches a coding agent in a PTY with its API traffic redirected
through a local proxy. That gives one interception point — recording, model
routing, policy — that works the same across agents which share no code.

```sh
omni claude          # launch Claude Code; record all LLM traffic
omni codex           # same, for Codex
omni --mode route --model-map claude-opus-5=claude-sonnet-5 claude
```

:::caution[Phase 0 — in progress]
Recording and reconnaissance. The CLI, the configuration system, session
recording, and the installer are implemented. Routing, the capability
adapter, and all-traffic interception are designed but not yet wired in;
every page that describes them says so at the top.
:::
